# WuFengBot

[部署说明](docs/deployment_guide.md) | [构建记录](https://github.com/ws126837251/wufeng-bot/actions) | [MIT 许可证](LICENSE)

WuFengBot 是围绕多群运营、抽奖、客服留言和商品转发持续维护的 Telegram 机器人。

本项目基于 [PolicrMini](https://github.com/Hentioe/policr-mini) 的验证核心和后台框架，增加了消息自动化、成员管理、抽奖、群主审批、客服留言中转及网站商品转发，并重做了日常群管理控制台。以下说明以本仓库当前源码为准；可选功能需要相应配置和 Telegram 权限。

## WuFengBot 增加和改进的功能

### 多群配置和设置复制

- 管理多个群组，每个群独立保存验证、自动化、抽奖、成员与记录。
- 控制台显示当前管理的群组，点击“切换群组”后自行选择目标；移动端选择后进入工作台。
- 可选择另一个群作为来源，确认后复制入群验证、欢迎语、消息自动删除、违禁词、白名单、关键词回复、机器人文案和自定义验证题。
- 设置复制会覆盖目标群的对应配置；定时任务、抽奖活动、成员、黑名单、历史记录和管理员授权保持独立。

### 消息自动化和可编辑文案

- 验证通过后发送欢迎语，可设置欢迎消息和机器人回复的自动删除时间。
- 关键词自动回复支持包含、完全一致、前缀匹配和大小写开关；每条规则最多配置 50 个关键词、8 个跳转按钮。
- 欢迎语和关键词回复支持姓名、用户名、用户 ID 占位符。
- 违禁词和广告关键词支持白名单、删除提示、禁言及封禁；24 小时阶梯处罚可单独开启，默认关闭。
- 定时群消息支持新增、编辑、暂停、恢复、试发和删除，并记录发送失败和重试情况。
- 控制台可按群编辑验证、抽奖、命令、审批等场景的机器人文案，并恢复默认值。

### 抽奖和邀请助力

- 创建抽奖，设置奖品、中奖人数、开奖时间、发布置顶和提醒文字。
- 支持按钮报名或自定义关键词报名。关键词可以直接发到群内，也可以回复对应抽奖消息；多场活动使用相同关键词时，需要回复目标活动以区分。
- 可开启报名消息自动删除，并设置延时；成功报名和重复报名的匹配消息会清理。
- 每场活动可独立开启或关闭邀请好友功能。好友经邀请链接进入目标群并完成入群验证后，增加邀请人的抽奖权重；关闭时邀请按钮和链接不生效。
- 查看参与名单、邀请权重、中奖名单；支持到时开奖、主动开奖和取消活动。
- 开奖保存参与者快照、随机种子和 SHA-256 名单摘要，控制台可查看开奖凭证。

“@全体成员”选项是在消息中显示提醒文字，不会实际通知全群每位成员。

### 成员、黑名单和群主审批

- 按姓名、用户名或数字 ID 搜索当前群成员。
- 可通过 Telethon / MTProto 手动或每日同步成员；同步会校验 Telegram 返回的总数与拉取数量，数量不完整时记录失败。
- 按群维护永久黑名单，支持拉黑、解除和再次入群拦截；群主、管理员及 WuFengBot 自身受保护。
- 群内 `/ban` 支持用户名、数字 ID、回复目标消息等方式，并记录处理原因和执行结果。
- 群主可分别授予管理员“后台访问、执行功能、修改配置”权限。
- 当前群主在控制台操作直接生效；管理员的管理写操作需群主在机器人私聊中同意后执行。系统已配置的自动动作按原规则运行。

成员同步需要额外配置 Telegram API ID / API Hash，并受 Telegram 返回数据和权限限制；项目未实现不活跃成员检测或小号自动识别。

### 客服留言中转

- 私聊欢迎页提供“联系客服（无法私聊请点击）”入口。
- 多位访客可以分别通过机器人给配置的客服（机器人拥有者）留言，无需客服在线或逐一发送邀请链接。
- 转发文字、图片和文件，并显示发送者姓名、用户名和数字 ID。
- 提供“继续转发 / 停止转发”按钮；拥有者可用 `/relay` 开启入口、`/relay stop` 关闭入口及全部访客中转。

当前源码实现的是“访客 → 客服”的留言转发，尚未实现客服回复回传。联系入口的成功提示用于确认中转会话已建立，当前未包含独立验证码挑战。

### 带图商品通知转发

- 网站使用同一 Bot 发送商品通知，并在消息中配置 `broadcast:v1:open` 回调按钮。
- 点击按钮后，机器人在私聊中列出当前账号可访问的群组和频道，选择目标后使用 `copyMessage` 复制原消息，保留图片和说明文字。
- 频道需要先登记到机器人并授予发消息权限；群组和频道的能力按各自类型使用。
- 可选的 Dujiao 网站对接支持配置读取和签名心跳。

商品上架触发、商品图片与通知按钮的生成在网站项目中完成。本仓库提供目标选择与原消息复制，不包含商城源码。

### 工作台和运行记录

- 日常控制台包含工作台、安全、消息、成员、抽奖、记录、权限、自定义验证模块，并适配移动端与桌面布局。
- 展示机器人初始化状态、缺失的 Telegram 权限、自动删除和定时任务异常。
- 定时权限巡检只检查和记录问题。
- 临时验证限制的解除计划持久化，并由定时任务补偿，支持服务重启后继续处理。

## 常用入口和命令

| 场景 | 命令 | 用途 |
| --- | --- | --- |
| 私聊 | `/start` | 打开功能快捷入口 |
| 私聊 | `/relay`、`/relay stop` | 建立或停止客服留言中转；拥有者操作公开入口 |
| 群内 | `/lottery` | 群主打开当前群抽奖中心 |
| 群内 | `/active` | 查看当前群正在进行的抽奖 |
| 群内 | `/draw` | 提交主动开奖操作 |
| 群内 | `/ban` | 永久拉黑指定成员 |
| 群内 | `/manage`、`/status` | 打开管理入口或检查机器人权限状态 |

管理命令仍需满足当前群的权限与审批规则。

## 保留的上游基础

- 入群验证和加群申请处理，包括图片、算术、网格、自定义题目等验证类型。
- 验证超时、答错处理和入退群服务消息清理。
- Elixir / Phoenix 后端、Telegex Bot API 接入、Telegram Mini App 登录及 Web 管理框架。
- 原 Web 管理端 `/admin/v2` 和相关资源管理代码仍保留；日常群运营主要使用 `/console/v2`。

## 已精简或调整的入口和行为

- 抽奖创建、参与名单和主动开奖统一进入抽奖中心，合并了重复的私聊快捷按钮。
- 未实现的“自定义验证预览”“重新验证”以及独立“禁言用户”空入口不再作为可用功能展示。
- 赞助、旧登录和旧控制台命令未接入当前 Bot 消息处理链；相关历史源码仍可能保留。
- 原定时工作状态检查中自动退群、取消接管的行为，改为非破坏性的权限巡检。Telegram 权限变化事件仍由相应处理链更新状态。
- README 使用 WuFengBot 的功能说明；上游截图、社区宣传和旧版本更新列表已从首页说明中移除。

## 配置与部署

源码部署使用根目录 [docker-compose.yml](docker-compose.yml) 构建当前 WuFengBot。配置模板为 [.env.example](.env.example)，具体步骤见 [部署说明](docs/deployment_guide.md)。

[docker-compose.dev.yml](docker-compose.dev.yml) 用于开发依赖；[docker-compose.prod.yml](docker-compose.prod.yml) 仍引用上游预构建镜像。部署本仓库新增功能请使用源码构建方式。
